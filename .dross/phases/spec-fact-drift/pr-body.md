## Decisions locked

- **new_names** 🔒 — A path listed in any plan task's `files` counts as planned, not missing. Anything else the phase introduces goes in a spec-level `new = [...]` list, written when the c-4 walk confirms a citation is new. *(Explicit and reviewable with no prose markup; task files are already the plan's record of what gets created.)*
- **symbol_shape** 🔒 — A symbol citation is a single backticked token `Ident(.Ident)*` with optional `()` that is dotted or call-shaped. Every qualifier must match (`pkg.Name` needs package pkg to define Name); no last-component fallback. CLI commands, flags, TOML keys and bare lowercase words are skipped. *(Backticks mostly hold commands and keys; a last-name fallback would let `quoted.String()` resolve against any String method and miss the motivating case.)*
- **scanned_fields** 🔒 — Scan present-tense claims only: spec criteria text and decisions `choice`; plan task `files`, `description` and `test_contract`. Skip every `why`, [[deferred]] entries and edge reasons. *(Those fields describe history or future work; the parked item's own why cites `quoted.String()` precisely because it never existed.)*
